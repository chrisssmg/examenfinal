Pregunta 1. Explica en tus propias palabras: ¿Que es un algoritmo? Describe los pasos que seguirias para resolver un problema de programacion.
Un algoritmo es una secuencia de pasos ordenados y finitos, no ambiguos que tienen como objetivo resolver un problema cotidiano. 
Para resolver un problema de progamacion primero Analizo cual es el problema y las variables involucradas, luego identifico los pasos que debo seguir y como debo de hacerlo, despues escribo el codigo usando el paso anterior posiblemente usando un diagrama de flujo, despues pruebo si los pasos seguidos funcionan y resuelven mi problema inicial y por ultimo busco mejorar y ser lo mas eficiente posible en la solucion sabiendo que mis pasos si son los correctos.

Pregunta 2. Explica en tus propias palabras: ¿Qu´e es un puntero en C++? ¿Para que sirven los operadores * y &?
Un puntero es aquel que se encarga de almacenar la direccion de memoria de una variable. El operador & sirve para obtener la posicion de la memoria de una variable mientras que el operador * se usa para acceder al valor almacenado en la dirección que apunta el puntero inicializado.

y como se accede a sus elementos?
Un array es una estructura de datos que permite almacenar una colección de elementos del mismo tipo bajo el mismo nombre de variable.

Pregunta4. Explica en tus propias palabras: ¿Que es el alcance (scope) de una variable? ¿Qu´e
diferencia hay entre una variable local y una global?
El scope de una variable es el alcance que tiene una variable que esta definida dentro del bloque de codigo.
La diferencia principal es que una variable global se puede usar en cualquier parte del codigo mientras que una variable local solo puede ser usada en la seccion donde fue definida.

Pregunta5. Explica en tus propias palabras: ¿Por qu´e usamos private y public en una clase? ¿Que es el encapsulamiento?

Usamos estos modificadores de acceso (public, private) para controlar quién puede ver y modificar los atributos y los metodos de un objeto.
El encapsulamiento se encarga de ocultar detalles internos del codigo y mostrar al usuario unicamente lo que necesita saber.
